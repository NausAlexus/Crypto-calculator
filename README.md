# Crypto Calculator

## Overview
Crypto Calculator is a user-friendly application built with React that allows users to convert one cryptocurrency to another seamlessly. The app provides real-time exchange rates and a simple interface for quick conversions.

## Features
- Intuitive user interface for easy navigation
- Real-time cryptocurrency exchange rates
- Support for multiple cryptocurrencies
- Responsive design for mobile and desktop use
- Simple input fields for quick conversions

## Installation
To get started with the Crypto Calculator, follow these steps:

1. Clone the repository:

# npm install
